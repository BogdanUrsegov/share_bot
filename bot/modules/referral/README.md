# Referral commands

- `/ref_create <name> <price|-> <viewer_id>` — create a referral link.
- `/ref_list` — list created links.
- `/ref_stats <link_id>` — show link statistics for the admin or configured viewer.
- `/ref_delete <link_id>` — delete a referral link.
- `/ref` — show command help.

Referral links use `/start ad_<name>`. Each `/start` is recorded with Telegram `language_code` and Premium status.
